# Security and private reporting

Do not create a public GitHub issue, comment, or screenshot containing passwords, tokens, keys, account identifiers, private customer details, legal matter contents, undisclosed vulnerabilities, or exploit instructions.

For a possible vulnerability or other sensitive case, use the product's [private support channel](https://wwdcmcp.smatdesigns.com/support) and state that the subject needs private handling. Do not add technical exploit details to the public tracker. Never assume private vulnerability reporting is enabled without verifying it.

If sensitive material has already been published, stop reposting it and contact private support. Rotate any exposed credentials with their issuing provider.

AppDev Atlas is independent of Apple, uses public research material only and cannot access private App Store Connect accounts. Include a public Apple URL when documenting source drift.
